macOS menu bar utility

Keep Codex rate limits visible.

Codex Toolbar puts your remaining Codex usage in the menu bar, with a detailed popover, automatic refresh, and a direct jump into the Codex desktop app.

View install options

Requires macOS 14 or later and the Codex CLI installed locally.

Features

  • See your remaining Codex quota without keeping the main app open.
  • Check reset timing and detailed usage in a quick menu bar popover.
  • Launch at login so your quota status is always available.
  • Optionally show additional categories, including Codex Spark.

Install

Quick Install

Download the latest release, open the disk image, and drag the app into Applications.

Source install

Clone the repository and run the installer script.

git clone https://github.com/mikeylong/codex-toolbar.git
cd codex-toolbar
./scripts/install_app.sh

Need Codex CLI?

Install it once with npm, then run codex to sign in and pair it with CodexToolbar.

npm i -g @openai/codex
