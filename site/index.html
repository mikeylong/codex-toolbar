macOS menu bar utility

Codex and Claude usage, in your menu bar.

Keep an eye on your remaining usage while you work. Choose Codex, Claude, or both. Each gets its own menu bar item and a focused usage panel.

View install options

For macOS 14 or later. Uses your signed-in Codex CLI or Claude Code CLI.

Your usage, a click away.

Open a provider's menu bar item to check what remains and when it resets. Both panels include View usage to open that provider's dashboard in your browser.

Separate panel examples from v0.1.21, shown with sample data. Available limits depend on your account.

  • Refreshes automatically, with a manual refresh in each item's right-click menu.
  • Launch at login to keep usage close at hand.
  • Uses your existing CLI sign-in. You don't need to keep an interactive CLI session open.

Choose what belongs in your menu bar.

Select Codex, Claude, or both when you first open the app. Your choice is remembered.

To change it later, right-click either menu bar item and select Choose providers….

Install

Quick Install

Download the latest release, open the disk image, and drag the app into Applications. Open it and choose the providers you want to see.

↓ Download DMG

v0.1.21 (Latest)

Source install

Clone the repository and run the installer script.

git clone https://github.com/mikeylong/codex-toolbar.git
cd codex-toolbar
./scripts/install_app.sh

Sign in to the providers you use

Only install the CLI for the provider you want to display. To show both, set up both on this Mac.

For Codex

Install Codex CLI, then run codex and sign in.

npm i -g @openai/codex

Codex CLI setup

For Claude

Install a current Claude Code CLI and sign in with your Claude subscription. API billing accounts don't provide subscription limits.

claude auth login
